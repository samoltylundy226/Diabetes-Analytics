# Power BI Dashboard Workspace

This directory is reserved for the interactive healthcare Power BI dashboard (`.pbix` source or template documentation) and exported visual screenshots stored in `screenshots/`.

## Planned Dashboard Pages

1. **Executive Healthcare Overview:** Total patients (`1,879`), overall diabetes diagnosis prevalence (`40.02%`), demographic breakdown (age, gender, ethnicity, socioeconomic status).
2. **Clinical Biomarkers & Comorbidities:** `HbA1c`, `FastingBloodSugar`, `BMI`, blood pressure, lipid profile, and hypertension/family history comparisons by `Diagnosis`.
3. **Lifestyle & Symptoms Profile:** Physical activity, diet quality, sleep quality, smoking/alcohol, and symptom frequencies (`FrequentUrination`, `ExcessiveThirst`, `BlurredVision`, `SlowHealingSores`, `TinglingHandsFeet`).

> **Note:** Dashboard construction is scheduled after exploratory data analysis and data cleaning validation are completed. Place dashboard screenshots in `powerbi/screenshots/` and link them in the root `README.md`.
