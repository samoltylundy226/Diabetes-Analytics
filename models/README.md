# Models Directory

This directory stores serialized model artifacts (e.g., `.joblib` or `.pkl` files) and model metadata generated by `src/models/train.py`.

Model binary files are ignored in `.gitignore` to keep the repository lightweight. Re-run the training pipeline locally to regenerate model artifacts.

> **Important Framing:** Models trained on this dataset perform **cross-sectional diabetes diagnosis classification** using existing patient records. They do **not** predict future diabetes incidence over time.
