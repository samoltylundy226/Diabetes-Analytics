- `processed/`: Cleaned, split, or feature-engineered outputs generated by `src/data/preprocessing.py` and `notebooks/02_data_cleaning.ipynb` (ignored from Git tracking except `.gitkeep`).

## Documented Data Quality & Modeling Considerations

1. **Constant Identifier/Privacy Column:** `DoctorInCharge` has only 1 unique value (`"Confidential"`) across all `1,879` rows and should be excluded from modeling.
2. **Patient Identifier:** `PatientID` is a sequential record ID (`6000–7878`) and must be dropped prior to ML training.
3. **Blood Pressure Ordering Anomaly:** `158` rows (`8.41%`) have `DiastolicBP >= SystolicBP`, which is clinically invalid and should be flagged during data cleaning.
4. **Sex-Specific Condition Anomaly:** `GestationalDiabetes = 1` appears in both `Gender = 0` (`89` rows) and `Gender = 1` (`98` rows), and `PolycysticOvarySyndrome = 1` appears in both `Gender = 0` (`42` rows) and `Gender = 1` (`42` rows). Treat these flags carefully and document them as data quality anomalies.
5. **Post-Diagnosis / Diagnostic Leakage Awareness:** `FastingBloodSugar`, `HbA1c`, `AntidiabeticMedications` (`309` positive in `Diagnosis = 0`, `214` positive in `Diagnosis = 1`), and clinical symptoms reflect existing diagnostic criteria or treatment status. Models trained with these features classify **existing diagnosis**, not future risk.
